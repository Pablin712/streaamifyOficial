# Sonidos de Notificación

Este directorio contiene los archivos de sonido para las notificaciones del chat.

## Archivos requeridos:
- `notification.mp3` - Sonido de notificación en formato MP3
- `notification.ogg` - Sonido de notificación en formato OGG (fallback)

## Cómo obtener los sonidos:

1. **Opción 1**: Descargar de sitios libres de derechos como:
   - https://notificationsounds.com/
   - https://freesound.org/
   - https://mixkit.co/free-sound-effects/notification/

2. **Opción 2**: Generar con código (ya incluido en el sistema como fallback)

## Sonido actual:
El sistema usa un tono generado por código como fallback si no encuentra los archivos MP3/OGG.
